# Java Hard Projects

Three Java projects based on the inheritance situations provided in the class PDF.

## Projects

### 1. Banking System — Multilevel Inheritance
Account -> SavingsAccount -> StudentSavingsAccount

### 2. Online Shopping — Hybrid Inheritance
Product -> Electronics / Clothing -> Laptop

### 3. Hospital Staff — Hierarchical Inheritance
Staff -> Doctor / Nurse

## Concepts Used

- Inheritance
- Multilevel Inheritance
- Hierarchical Inheritance
- Hybrid Inheritance
- extends keyword
- private variables
- Setters
- Display methods

The project structures, class names, variables, methods, and main logic follow the supplied inheritance situations PDF.
